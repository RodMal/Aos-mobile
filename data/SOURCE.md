# Where this data comes from

| File | Source |
| --- | --- |
| `factions/sylvaneth.json`, `factions/seraphon.json`, `factions/universal.json`, `lores.json`, `ruleset.json` | Generated by [RodMal/BSData-parser](https://github.com/RodMal/BSData-parser) (commit `1d8e554`) from [BSData/age-of-sigmar-4th](https://github.com/BSData/age-of-sigmar-4th) at commit `28ca9405c89880a6cea0480603247993275dfb6b`. Copied and pruned by `scripts/extract-data.mjs`: Regiments of Renown are removed and only the lores these factions reference are kept. No value is changed. |
| `maps/into-the-fire.json` | BSData-parser `packages/aos-maps/maps/ghb-2026-27-into-the-fire.json`: board, territories and objective positions for the GHB 2026-27 battleplan. |
| `terrain/into-the-fire.json` | Authored for this app. Positions follow the terrain icons on a community cheat sheet (accurate to about 1-2"); sizes and rotations are approximations. |

To refresh the BSData-derived files, rebuild the data in BSData-parser (`pnpm data:sync`) and run:

```sh
pnpm data:extract /path/to/BSData-parser/packages/aos-data/data/v1
```

Never edit the JSON under `factions/`, `lores.json` or `ruleset.json` by hand. Rule behaviour lives in `src/rules`, keyed by the ability ids in this data.
