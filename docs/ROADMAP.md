# Roadmap

Each milestone ends with something playable on a phone.

| #   | What you can do                                                                                                                                                              | Status                              |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| M0  | Open the deployed app and see both armies on Into the Fire                                                                                                                   | done                                |
| M1  | Pinch and pan the table; move units (drag, re-form, adjust single models) with legality feedback; pass phases through five rounds                                            | in progress                         |
| M2  | Play a full five-round game against a baseline NPC: shoot, charge, pile in, fight, casualties, objectives, scoring, priority, command points, four commands, save and resume | engine and NPC done; UI in progress |
| M3  | Magic, manifestations, reaction commands, battle tactics, cover, line of sight, Fly, season rules, alternating deployment, offline install                                   | planned                             |
| M4  | Every rule on both army lists                                                                                                                                                | planned (needs the Seraphon list)   |
| M5  | Hard NPC with three difficulty levels                                                                                                                                        | planned                             |
| M6  | More battleplans, list import, more units, data refresh                                                                                                                      | planned                             |

## Army lists
