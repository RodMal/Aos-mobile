# Rules decisions

Where the engine had to interpret or simplify a rule, it is written down here so the owner can overrule it. Newest entries go at the bottom of each section.

## Simplifications (to be removed)

| #   | Area           | What the engine does now                                                                                                                                       | Planned                             |
| --- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| S1  | Deployment     | Both armies are set up automatically in legal positions.                                                                                                       | Alternating deployment in M3.       |
| S2  | Movement paths | Each model moves in a straight line from start to end. The path is checked against enemy combat range (3"); it is not checked against other models or terrain. | Waypoints and model blocking in M3. |
| S3  | Height         | The table is flat. Terrain is a 2D footprint; climbing costs no movement.                                                                                      | Revisit with line of sight in M3.   |
| S4  | Priority       | Player 1 takes the first turn of every round.                                                                                                                  | Priority roll in M2.                |

## Interpretations

| #   | Rule            | Reading used                                                                                                                                                           |
| --- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| I1  | Objective range | A model contests an objective when its base is within 3" of the 40mm marker, i.e. within 3.79" of the objective's centre.                                              |
| I2  | Terrain types   | Authored layout for Into the Fire: ruins give cover and are unstable; outcrops give cover and are obscuring; the two spires are the Places of Power and are obscuring. |
